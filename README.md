# CRM визового центра

Веб-приложение для команды из шести ролей: директор, менеджер по рекламе, менеджер по клиентам, курьер, юрист, бухгалтер. Каждая заявка проходит 21 этап — от лида до подписанного акта. У каждого этапа есть исполнитель, тайм-лимит в рабочих часах и список условий, без которых заявку нельзя передать дальше.

Логика взята из документа «Визовый центр — архитектура обработки заявок».

## Что умеет

- **Мои задачи** — заявки, которые сейчас на этапе вашей роли. Сначала идут просроченные.
- **Воронка** — все заявки по этапам, с поиском и фильтром по категории.
- **Карточка заявки** включает:
  - текущий этап и исполнителя;
  - срок и светофор;
  - чек-лист «без чего не передавать»;
  - кнопку передачи следующему исполнителю;
  - возврат на прошлый этап с комментарием;
  - эскалацию директору;
  - историю заявки;
  - оплаты.
- **Панель директора** показывает:
  - что ждёт вашего решения;
  - эскалации и просрочки;
  - воронку;
  - источники лидов за месяц;
  - долг после выдачи;
  - назначение ролей сотрудникам.
- **Светофор**: зелёный — в лимите, жёлтый — осталось меньше четверти лимита, красный — просрочено. Время считается только рабочее: пн–пт, 9:00–18:00, без праздников РК.

### Правила, которые нельзя обойти

Они проверяются в самой базе данных, а не только в интерфейсе:

1. Работа после договора начинается только после предоплаты.
2. Пока оплата не полная, документы клиенту не выдаются: этап «Выдача клиенту» не закрывается.
3. Оплаты и сумму договора вносят только бухгалтер и директор.
4. Сотрудник без назначенной роли не видит заявок.

## Запуск — один раз, около 20 минут

### 1. База данных (Supabase, бесплатный тариф)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект. Регион — ближайший, например Frankfurt.
2. Откройте **SQL Editor**, вставьте содержимое файла `supabase/schema.sql` и нажмите **Run**.
3. В **Authentication → Providers → Email** включите вход по e-mail. Если не хотите подтверждать почту письмом, выключите **Confirm email**.
4. В **Project Settings → API** скопируйте **Project URL** и **anon public key**.

### 2. Сайт (Vercel, бесплатно, работает с приватным репозиторием)

1. Войдите на [vercel.com](https://vercel.com) через GitHub и нажмите **Add New → Project**. Выберите репозиторий `shymkentinvest`.
2. В **Environment Variables** добавьте две переменные:
   - `VITE_SUPABASE_URL` — Project URL;
   - `VITE_SUPABASE_ANON_KEY` — anon public key.
3. Нажмите **Deploy**. Через минуту получите адрес сайта.

### 3. Первый вход

1. Откройте сайт, нажмите «Регистрация» и зарегистрируйтесь своим e-mail.
2. В Supabase → SQL Editor выполните запрос, подставив свой e-mail:
   ```sql
   update public.profiles set role = 'director' where email = 'ваш@email';
   ```
3. Обновите страницу — откроется панель директора.
4. Сотрудники регистрируются сами. Роль каждому вы назначаете в разделе «Директор → Команда».

## Разработка

```bash
npm install
cp .env.example .env   # вписать URL и ключ Supabase
npm run dev            # http://localhost:5173
npm test               # тесты расчёта рабочих часов
npm run build
```

## Где что менять

| Что | Файл |
| --- | --- |
| Этапы, исполнители, тайм-лимиты, условия передачи | `src/lib/stages.ts` |
| Категории виз и нормативный срок госоргана | `src/lib/stages.ts`, `CATEGORIES` |
| Праздники и переносы выходных | `src/lib/workhours.ts`, `EXTRA_HOLIDAYS` |
| Источники лидов | `src/pages/NewDeal.tsx`, `SOURCES` |
| Права доступа и правила оплаты | `supabase/schema.sql` |

Плавающие праздники (Курбан айт) и переносы выходных каждый год добавляйте в `EXTRA_HOLIDAYS`.
